# Open Companion Listener v0.1.3

## Send keystrokes and mouse commands to a Windows PC using Bitfocus Companion.

Open Companion Listener is a free, open-source Windows application that receives commands from Bitfocus Companion and executes them on your computer.

Send individual keystrokes, keyboard shortcuts, mouse clicks, and scroll commands from a Stream Deck, Loupedeck, or any control surface supported by Companion.

You can also launch applications, open files, and execute scripts.

The listener runs quietly in the Windows system tray. Companion can run on the same computer or another machine on your local network.

No subscriptions. No cloud accounts. No license activation.

Free and open source under the MIT license.

## Keyboard controls

Send individual keys, including F1–F24, numpad and navigation keys, or build shortcuts using modifier checkboxes and a key dropdown. Actions support press, hold and release. Num Lock has separate Toggle, ON and OFF controls.

## Mouse controls

Send left, right or middle clicks, hold and release mouse buttons, and move the pointer relative to its current position. Scroll vertically or horizontally with a separate direction control and an adjustable amount of 1–20 notches.

## Additional functions

Launch applications with arguments, open files, folders and URLs, or run scripts through an installed interpreter or file association. Windows Settings pages and classic Control Panel tools are available from dropdowns. Script interpreters, such as AutoHotkey, must be installed separately where needed.

## 38 optional Companion presets

The module includes presets for Windows shortcuts, Chrome shortcuts, common editing shortcuts, mouse scrolling and Windows Settings. Drag presets from Companion's **Presets** tab onto your buttons, or configure your own actions. Installing the module does not add buttons or change existing pages. Keyboard presets act on the currently focused window.

## How the two components communicate

The **Windows listener** runs on the PC receiving commands. The **Companion module** adds the actions and presets to Bitfocus Companion.

When a button is pressed, the module sends an authenticated HTTP command to the listener using its IP address, API port (default `17992`) and private pairing key. The listener checks the request and trusted Companion IP before performing the action.

The settings dashboard is available only on the Windows PC at `http://127.0.0.1:17993/`.

## Install the Windows listener

1. On Windows 10/11 x64, extract the verified Windows ZIP to a permanent folder. Run `OpenCompanionListener.exe` as your normal Windows user.
2. Find its system tray icon. Double-click it or choose **Open GUI** from the right-click menu. The browser dashboard does not open automatically.
3. In Settings, choose the listen address, set the trusted Companion computer's IP and API port, then save. Copy the pairing key into the Companion connection when configuring it below.
4. For connections from another computer, allow inbound TCP `17992` (or your chosen API port) in Windows Firewall **only from that Companion computer**.
5. Optionally enable **Start with Windows** after placing the EXE in its permanent folder. To stop the listener, choose **Exit** from its tray menu.

The Windows EXE does not require Node.js or Python.

## Install the Companion module

Use **Companion 4.1 or later with API 1.13 and the node22 runtime**, and **Node.js 22.8 or later within the 22.x line** for module installation. This is the API minimum, not certification of every Companion version.

1. Extract the verified Companion ZIP to a staging folder. Open a terminal inside `companion-module-community-openlistener`.
2. Confirm `node --version` reports a supported 22.x version. Run these commands, stopping if any fails:

   ```text
   npm ci --omit=dev --ignore-scripts --no-audit --no-fund
   npm run validate
   npm test
   ```

3. Copy the prepared `companion-module-community-openlistener` folder into the developer/extra module **parent directory** configured in Companion. This is not an in-app ZIP upload package.
4. Restart Companion when safe. Add an **Open Companion Listener** connection and enter the Windows PC's IP, API port and pairing key.
5. Create buttons using the module's actions, or drag in optional presets.

Dependencies require npm registry access during installation; normal operation is local. Before upgrading an existing installation, export the Companion configuration and back up the module. See the [installation and rollback guide](https://github.com/ninoleto/OpenCompanionListener/blob/v0.1.3/docs/COMPANION-INSTALL.md).

## Basic security

Use a trusted local network or private network connection. HTTP commands are **authenticated but not encrypted**. Keep the pairing key private, restrict the API port with Windows Firewall, and never expose the API or dashboard to the public Internet.

A paired Companion host can send input and launch applications or scripts under your Windows account. Pair only with a computer you trust, and do not run the listener as Administrator. See [SECURITY.md](https://github.com/ninoleto/OpenCompanionListener/blob/v0.1.3/SECURITY.md) for details, including replay-protection limits across full process restarts.

## Known limitations and support

v0.1.3 is the first public release. Automated tests and GitHub Actions passed; the corrected EXE passed an isolated smoke test and a completed Defender scan with no reported threats. These checks do not establish that every feature or Windows configuration has been tested.

- The listener targets Windows 10/11 x64 and runs in an interactive user session.
- The EXE is unsigned, so Windows may show an unrecognized-publisher warning.
- Input follows Windows focus and security restrictions; elevated or locked desktops cannot be assumed controllable.
- Detailed tray/startup, all-preset, interrupted-input and real-host migration/rollback coverage remains incomplete. OS acceptance of a launch request does not mean the application finished its task.

See the [test record](https://github.com/ninoleto/OpenCompanionListener/blob/v0.1.3/SMOKE_TEST.md) for scope. Report bugs or suggestions through [GitHub Issues](https://github.com/ninoleto/OpenCompanionListener/issues), including your Windows and Companion versions, reproduction steps and sanitized logs. Never include pairing keys or private settings.
